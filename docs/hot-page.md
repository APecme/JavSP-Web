# 热片页面

> 当前行为以文末“第二轮：统一影片墙、检测弹窗与网络诊断”为准；前文保留第一轮实现记录。

本轮新增“热片”页面的基础发现与站点检测功能；此前的 30 站调研见 [来源调研](hot-sources/README.md)。

## 使用

- 左侧点击 **热片**，使用 **全部 / 有码 / 无码** 标签切换。键盘支持左右方向键、Home、End，筛选状态保存在当前浏览器。
- **最新**：每个来源按其提供的日期降序。FALENO/DAHLIA 使用主页发布区的配信日期，FREE JAV BT 使用来源列表日期，不把收录日假称官方发行日。
- **最热**：保留来源榜单顺序，分来源/码类展示；没有跨站综合热度分数。品牌榜周期未公布时会明确标注。
- 初次点击 **刷新列表** 获取数据，此后进入页面只读缓存。结果逐步显示；失败保留上次成功快照并提示过期/失败。服务端不以验证页、空页或解析错误替换成功列表。
- 点击 **检测连接** 会批量检测用户指定的全部 **30 站**，不受当前影片标签影响。展开“来源连接状态”查看进度、状态、HTTP 状态码、耗时和检测时间。

## 范围与限制

**检测 30 站不代表 30 站影片都已接入。** 当前影片列表适配器：

| 来源 | 有码 | 无码 | 最新 | 最热 |
|---|---|---|---|---|
| FALENO | ✓ | — | 首页带配信日期的作品发布区 | 品牌站内排名，周期未公布 |
| DAHLIA | ✓ | — | 首页带配信日期的作品发布区 | 品牌站内排名，周期未公布 |
| FREE JAV BT | ✓ | ✓ | 来源分类最新列表 | 来源分类日榜，算法未公布 |

每个来源只读取一个列表页，最多返回 40 条，不声称全量历史或完整分页。其他站点本轮仅检测连通性。码类按来源栏目归类，不根据标题或文件名推测。卡片提供文本资料与原站链接，不请求远程封面、播放、种子、磁力或下载脚本。

连接结果区分：可达、年龄确认、地区限制、验证拦截、维护、疑似域名停放、前端空壳、拒绝访问、限流、DNS/证书错误、连接/读取超时等。**可达**仅表示取得普通 HTML，不能证明某个榜单可解析。

本轮检测为**运行服务所在机器的匿名直连**；不使用浏览器登录态、CookieCloud、系统代理环境变量、刮削代理或免代理镜像，不提交年龄确认、不解验证码。用户网络下的实际结果与开发环境可能不同。使用条款/数据获取与展示权限应由部署者确认，不绕过站点限制。

## 权限、执行和缓存

- 登录用户可浏览与刷新固定列表；**批量检测仅管理员**。未登录返回 401，操作员检测返回 403。
- GET 仅取内存状态，不发送外网请求；外网请求只由显式 POST 触发。
- 检测：全局单批运行，最多 6 个并发，60 秒冷却。重复点击共享正在执行的批次，不重复提交。
- 列表：全局单批运行，最多 3 个并发，每个来源/码类/排序组合 120 秒冷却；缓存 30 分钟后标过期，刷新失败保留最后成功数据。
- 检测与列表状态均为**进程内缓存**，重启后重置。默认单 worker 部署；多进程部署会各自缓存/限频，并不提供跨进程作业共享。
- 网络只允许 HTTPS、公网 DNS/IP，逐跳校验并固定连接 IP，保留原主机 TLS 校验；阻止 HTTP 降级、私网/本机/元数据地址与携带凭据的 URL。不关闭证书验证。
- 每个响应最多 1.5 MB，最多 4 次跳转，连接/读取与总读取期限有限；无自动重试。系统 DNS 查询仍受操作系统解析器超时控制。
- 异步后台处理，不让一个慢站阻塞整页。前端只在热片页面可见且任务未完成/冷却未结束时轮询；失败有限重试；分类请求有代次校验，避免旧响应覆盖新标签。

## API

| 方法 | 路径 | 参数/请求体 | 作用 |
|---|---|---|---|
| GET | `/api/hot/connections` | 无 | 30 站最近结果、批次进度、检测权限 |
| POST | `/api/hot/connections` | `{}`，管理员 | 开始/复用批次，202 |
| GET | `/api/hot/films` | `category=all\|censored\|uncensored`，`sort=latest\|hot` | 当前选择的来源分组、缓存作品、刷新状态 |
| POST | `/api/hot/refresh` | `{"category":"all","sort":"latest"}` | 刷新当前选择涉及的固定列表，202 |

拒绝额外请求体字段，不接受任意站点 URL、脚本或文件路径。输出只包含固定说明和结构化资料，不返回远程 HTML、Cookie、响应头或原始异常内容。

- 生产 FastAPI 集成：已登录状态下的 30 站目录、无码最热数据查询、POST 派发及两份静态资源加载通过；未对真实生产服务执行检测/刷新。

- CookieCloud 设置新增上游官方 README 列出的 Chrome、Edge 商店入口及官方 Releases；Chrome 链接也适用于支持 Chrome 商店的 Chromium/Brave。上游未给已核实的 Firefox 商店入口（需自行编译），Safari 支持未确认，不伪造商店链接。

### Clash / Mihomo 诊断

地区受限条目可以打开出口诊断窗口，管理员填写：

1. `external-controller` API 地址和 Secret（不是 YACD 等前端静态面板网址）；
2. 本机/内网 HTTP/mixed 代理地址（容器 localhost 是容器本身，可使用 host.docker.internal）；
3. 1–3个固定站点目标；
4. **再次勾选确认**临时切换 GLOBAL/全局模式、影响该 Clash 所有流量并向 ipapi.co 查询出口 IP/地区。

只测试可由 GLOBAL 直接选择的叶子节点（最多100个），不把自动策略组当独立节点。每个节点读取出口IP/地区，并通过指定代理请求目标网页，分别记录可达、地区限制、年龄确认等状态。公网HTTP控制器拒绝明文Secret；诊断代理目前仅支持本机/内网HTTP/mixed，不接受任意目标URL。正常请求仍走直连；此功能不自动修改全局刮削代理配置。

完成、取消或关闭诊断窗后尝试恢复原模式和GLOBAL选择，并回查；恢复失败会明确告警。整个诊断最多15分钟（另加当前请求/恢复时间），进程意外退出或网络中断时不能保证恢复，用户必须保留面板手动恢复能力。不得在无人知晓的共享Clash上测试；出口服务限流失败时不猜地区，也不把IP失败节点列作可导出成功节点。

**完整YAML导出**必须提供原配置：控制器API不返回完整节点凭据，不能仅凭面板地址凭空生成完整配置。上传最大1MB的原YAML，选取本次成功节点后生成下载：

- 保留节点、provider、DNS、原规则及其他配置，新建每个已测可达域名专属策略组；每组仅包含真正通过该域名的节点，而不是所有成功节点的混合。
- 若选中节点来自provider，则原YAML必须包含相应provider，生成精确名称过滤；节点不存在且无provider时拒绝导出。
- 仅对实际测试通过的站点域名添加分流，不声称未测域名可用；站点重定向/CDN域名不自动扩展。
- 输出是完整配置，含原配置中的节点密钥/订阅等敏感信息，仅作为`no-store`附件返回，不记录、不持久化；注释会被重新序列化。
- **先备份、用Clash/Mihomo校验后再手动覆盖**。不同内核版本/provider内容和运行环境仍可能影响加载，不保证任意原配置都能跨版本直接使用，也不自动覆盖、安装或重载磁盘配置。

新增管理员API：`GET/POST /api/hot/clash`、`POST /api/hot/clash/cancel`、`POST /api/hot/clash/export`。所有状态与Secret均只在进程内存；浏览器不保存Secret或上传的原YAML。

### 本轮验证边界

Clash控制器状态切换、故障/取消恢复和YAML生成有离线模拟测试；未连接或切换用户实际Clash。实际出口与地区服务可用性必须由管理员在页面确认后实测。Chromium离线演示可验收弹窗、统一墙、CookieCloud跳转与诊断确认，但不会连接真实Clash或导出真实凭据。

当前任务状态/限流是进程内的，诊断请使用单 worker 部署；多个 Web worker 或外部客户端同时修改同一个 Clash 会导致状态互相干扰。控制器和代理必须指向同一 Clash 实例；仅填地址无法自动证明二者对应。
