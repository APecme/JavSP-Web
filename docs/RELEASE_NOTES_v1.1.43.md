# JavSP WEB v1.1.43

本次基于 v1.1.42 正式版修复，不包含后续 main 分支的体验版功能。

- 修复网页目录扫描未应用忽略目录规则的问题，同步应用“跳过已有 NFO 的目录”，避免将已整理目录再次加入批量任务。#19
- 修复相对输出模板重刮时不断嵌套输出目录的问题：含 `{num}` 的模板按目录结构和番号识别已有输出位置，支持标题变化、截短标题和 `./` 前缀。已有嵌套目录不会自动搬迁，覆盖策略继续生效。#20
- OpenAI 翻译引擎改用区分标题/简介的中文指令；温度可配置，默认 0.1。拒绝空白、截断、明显过长和大量重复等异常结果；异常标题保留原文并记录警告，避免污染 NFO 与目录名。接口故障仍报错。#21
- 刮削预设的“文件夹整理”新增“使用软链接整理文件”，支持跨盘并保留源视频；与硬链接互斥，支持多分 P、覆盖回滚和撤销整理。#17

## 软链接使用提示

开启“整理文件到输出目录”，关闭硬链接，开启软链接。源视频路径需持续可访问；Docker 中播放器也必须以相同路径挂载源目录。Windows 需要具备创建符号链接的权限（开发者模式或管理员权限）；权限不足时明确报错，不自动移动源视频。
