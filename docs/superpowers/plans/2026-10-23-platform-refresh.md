# 2026-10-23 功能与界面重构方案及实施计划

用户要求：先逐项出具完整方案，再由每项独立的 DeepSeek Harness 编程，主代理审批。授权开发与本地验收；不自动提交、部署或发布。保留原工作区大量既有修改；Git 元数据只读。使用 `tmp/oct23-work/` 中不含数据和凭据的独立副本，按基线进行三方整合。

## 1. 评论同源转发

新增独立 FastAPI router 和服务端请求层。`GET /api/runtime` 的 `comments_url` 指向 `/api/comments`，浏览器公开评论与身份 API 都经此路径；上游仅由服务端 `JAVSP_COMMENTS_URL` 指定。逐方法和路径白名单允许 config、threads/comments、评论删除/like/reports、identity、me/profile/comments/logout/logout-all/pin；不允许 admin、用户指定完整 URL 或重定向逃逸。现有站点登录是本地转发的准入条件；不把站点 Cookie、Authorization、任意代理头或上游 Set-Cookie 转给另一端，只允许评论身份 token、必要 JSON 头和受限 query。请求与响应有大小上限、超时，保留 401/403/428/429 和 Retry-After；网络失败转为可读 502/504，脱敏错误。

Cloudflare 验证有 hostname 和 frame origin 约束，不能直接把验证 HTML 放到任意部署域。拆分 `comments_verify_url` 与同源 API base；前端校验上游验证窗口来源、nonce、action、source。需要向用户明确：数据请求经服务器，第三方验证组件仍依赖验证域及 Cloudflare；不关闭校验、不内置管理员密钥。代理后上游看到站点出口 IP，不伪造 CF-Connecting-IP；记录此限流粒度限制，不许静默关闭防滥用。

验收：认证拒绝、白名单及编码绕过、token/主站 Cookie 隔离、超时/断网、分页/回复/点赞/举报、身份接口、428、验证消息来源与相对 URL、禁用服务；有意义的离线测试，浏览器检查评论 fetch 均同源。

## 2. 自更新持久化

调查 `app_supervisor.py`、`app_update.py`、`updater.py`、数据目录和 Docker 入口。现有设计把应用保存在 data/updates/apps，启动器读 app-current/base-image，不能把“更新状态存在”当已持久化。先构造首次运行、旧记录迁移、应用更新成功、同一镜像重启、进程环境变化、设备重启语义、显式镜像更换、损坏更新、失败回滚等测试，再决定修复点。持久选择成功版本；真实镜像替换和依赖不兼容仍有明确优先级，不偷偷覆盖用户选择。写状态原子完成，崩溃可恢复；健康失败保留可见原因。若必须替换基础镜像启动器，UI 与文档如实说明一次性迁移要求，不能虚称应用热更新能替换 PID1。

验收：至少两个独立启动周期使用更新后版本，基本镜像未变不回退；失败才回滚；当前/基础/目标版本区分。测试不更改线上容器或真实更新数据。

## 3. 页面布局与视觉

以片库 `--lc-*` 的语义色、圆角、卡片、字体和留白为基准，真正调整结构，不只追加换色覆盖。手动刮削：紧凑输入与预设主操作卡，独立任务队列及可折叠筛选。自动刮削：目录监控、定时、下载完成三个明确区域和运行状态。下载：摘要、筛选、列表、策略折叠的层次。爬虫：来源列表与编辑/测试主从布局。预设：选择列表与分组编辑器，移动端有顺序。设置：明确分类导航/分组，更新、连接、账号与 AI 组各自清晰。AI：左会话列、对话区、固定输入区域。个人中心和登录也使用同一系统。保留 DOM hooks、权限、表单与业务 API，不把功能实现细节放到页面。

验收桌面 1440/1024、手机 390/320，明暗主题、长文本、空态、失败态、hidden/disabled、键盘及 reduced-motion；每页截图，图标与新功能整合后再验收。

## 4. 左侧导航

电脑 240px 完整栏与 72px 图标栏；手机 56px 左侧常驻图标栏，展开为左侧抽屉并带遮罩，选择后关闭抽屉。导航纵向可滚动，主区宽度为剩余空间，禁止顶部菜单。状态区分 desktop collapse 与 mobile drawer，不沿用旧 first-letter 假图标。菜单图标+文字，aria-current、aria-expanded、title、触摸目标、Escape/遮罩关闭与焦点恢复；旧存储状态兼容。为热片/下片预留后续导航注册，等待功能含义确认。

## 5. SVG 图标

新增本地 `icons.js`，统一 `window.JavspIcons.render(name, options)`（返回受信静态 SVG），24 viewBox、currentColor、统一 stroke；图标名白名单，用户文本不得插入 SVG。图标仅装饰时 aria-hidden，按钮提供可访问名称。替换 HTML/动态 JS 中操作符号：展开折叠、侧栏、关闭、前后、加减、删除、刷新、搜索、发送、停止、文件夹、编辑、播放、详情等。CSS 伪元素符号一并清理；正常文本的箭头/单位不机械替换。静态资源在真实页、登录与 demo/PyInstaller 可用；最终由主代理更新 demo 资产列表和顺序。

## 6. 片库命名

可见“概览”改为“片库”，包括 nav/header、说明、用户指南与空态；内部 overview hooks 和持久 key 保持兼容，不做大范围内部重命名。旧 active-view 恢复为片库，搜索分类和文件夹均不丢失。demo 由主代理最终构建。

## 7. 影片详情关闭

标题栏动作组按“编辑资料、关闭”顺序，仅一个关闭按钮；窄屏标题可换行，动作按钮不被挤走。标题栏 sticky，分区导航独立，关闭位于编辑右侧，扫描任务隐藏编辑但保留关闭。剧照 dialog 自己的关闭不影响父层；键盘 Esc、焦点、滚动和后台刷新保持。

## 8. 热片（等待来源定义）

独立标签页，不把随机或伪造顺序当真实热榜。用户需确认数据源与热度：外部榜单则服务端固定来源抓取/缓存/分页，记录来源与更新时间、离线和解析失败；站内热度则定义可解释的统计窗口和排序，服务端查询。卡片复用片库设计，支持定位已有片库条目。未获得下载授权不能自动添加种子。

## 9. 下片（等待业务含义）

用户需确认是下载入口、待下载清单或下架影片。若下载入口：搜索来源、结果详情、显式选择下载器/保存位置、确认后添加，并对 URL/magnet 与权限校验、避免重复；若待下载清单：持久收藏、筛选状态、选中后手动发往下载器；若下架片：有证据来源及日期，不根据网络错误判下架。不在确认前创建误导页面或虚假数据。

## 10. 目录监控

新增独立目录监控模块与管理员 router、原子持久规则/观察状态。跨 NAS/Docker/Windows 采用有界轮询，可后续扩展原生事件；默认 30 秒扫描、稳定等待 60 秒，用户可调且有范围。支持规则启停、路径、预设、子目录、排除、首次扫描选项；仅已挂载的容器路径。文件签名为相对路径+size+mtime_ns，多次稳定后进入现有 create_tasks 队列，多P按现有任务聚合；临时下载后缀、符号链接循环、输出/data/updates目录回流排除。持久已提交签名，重启恢复不重复，新增与变化可触发；任务在执行时不重复入队，目录离线/权限失败保留观察状态并显示问题，恢复后重试，关闭规则立刻停新提交。扫描不持主线程或全局业务锁，不读取真实媒体验收。

验收：临时目录测试新增、持续写入、稳定、重复扫描、重启、已有文件策略、禁用、移除、多P、排除、错误恢复、权限及并发。规则的首次处理选项等待用户答复，默认仅监控新增/变化。

## 执行顺序与审批

- 每项一个 `delegate_to_agent(agent_type="deepseek")` 独立任务，不允许代理再委托。
- 第一批：评论转发、自更新、目录监控，分别独立副本。主代理审核变更与新增测试，再按基线三方整合。
- 第二批：页面布局、左侧导航、命名与详情位置；共享文件的任务按当前集成版本顺序启动，或独立补丁整合。
- 第三批：全站 SVG，及用户定义后的热片、下片各一个代理。最后 SVG/布局兼容审查。
- 每项先失败测试后实现；UI 不写纯实现镜像测试，采用交互验证。每项返回文件清单、测试结果、限制和差异。
- 所有 JS 逐文件语法、Node 全回归、Python 全回归、demo 重建与源一致；42 组旧验收不替代新版本实测。
- 主代理发现问题退回该功能 DeepSeek 返修，直至验收；保持任务状态与未解决项可查。发布需本轮另行明确指令。
