# bata 更新说明

- 修复单独提交某个分 P 时被拆开刮削：同目录、同番号的分段合并为一个任务，在同一影片目录输出 CD1/CD2 文件；补充 P1/P2 命名识别。明确多选保持所选范围，下载完成回调不收集其他下载文件。
- 评论、点赞和举报改为按风险验证：先检查额度，必要时才要求 Cloudflare 挑战；通过后当前评论会话获得信任期，持续滥用逐级临时限制。配合本次 JavSP-Comments 后端更新使用。
- 评论管理新增作者 IP、用户 ID 来源筛选，以及 IP/用户封禁、自动临时封禁查看与解除；IP 加密保存，公开评论不显示来源。
- 修复影片详情后台刷新时中文片名与番号闪烁；概览历史记录改为“刮削 N 次”，明确显示刮削失败或已停止。

- 安全修复：修改密码或删除账号后立即撤销旧登录；普通操作员无法读取预设密钥、原始配置和爬虫源码；登录失败按 IP 和用户名限流，HTTPS 登录 Cookie 加 Secure。反向代理部署须设置 `JAVSP_WEB_TRUSTED_PROXIES`，仅信任指定代理提供的客户端 IP 和协议。
- 评论个人中心新增退出当前设备、退出所有设备和修改 PIN，支持使用 `用户名#标识` 登录；配合 JavSP-Comments 的身份额度、举报分页和会话撤销修复使用。
- AI 模型列表兼容嵌套列表和模型名称字段；429 限流最多重试两次，同站点重定向保留认证。
- 修复 Jellyfin 密钥认证：使用标准 MediaBrowser 认证头，并支持媒体库列表兼容端点。
- 刮削预设新增已有影片覆盖方式：从不、总是、按文件大小、仅保留最新。大小或修改时间相同时保留已有版本；保留时不移动源影片，不改写已有资料与图片。多段影片先统一检查再整理，替换失败会回滚影片文件。曾覆盖已有内容的任务不提供文件还原。
- 概览与详情参考 jellyfin-library-poster 重做：封面取色渐变背景、左侧标题和右侧倾斜圆角海报拼贴，影片墙保留独立播放按钮；根据输出路径、路径映射和所选媒体库匹配影片，打开对应服务器的外部播放页面。匹配到多个服务器时可选择播放入口。

- 重做概览媒体库：突出封面墙，加入番号、片名和女优搜索，保留排序、分页、多选与隐私模式。
- 重做影片详情：重新安排封面与资料、横向剧照和评论，文件路径与刮削记录可展开查看。
- 重新生成 247 张头像，去除上下黑边后从正中心裁切。
- 普通评论默认直接发布，疑似广告待审核；后台可分别设置用户名和评论禁用词。
- 评论后台改为表格，支持组合搜索、表头排序和批量发布、删除、恢复、处理举报。
- 删除的评论进入回收站，默认保留 30 天，可设置 1–90 天；到期后定时彻底清理。

已有待审核评论保持原状态。广告规则为初步筛选，管理员仍可处理误判与举报。调整保留天数只影响之后删除的评论。
