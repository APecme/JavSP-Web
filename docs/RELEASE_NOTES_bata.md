# bata 更新说明

- 概览采用新的影片封面墙，展示番号、标题和演员，支持排序、分页和批量选择记录。
- 新增隐私模式，模糊封面墙、详情海报与剧照，并记住当前浏览器的选择。
- 调整影片详情的资料、图片和日志布局，改善手机端显示。
- 影片详情接入共享评论区，无需注册即可使用昵称或匿名评论；支持分页、刷新和举报，评论审核后显示。
- 系统设置可填写评论昵称，评论框也可直接修改；后台刷新影片资料时保留正在输入的评论。
- 评论读取失败时可重试，评论服务无法连接不影响刮削与影片浏览。

默认评论接口为 `https://comments.rtioo.com`，可通过 `JAVSP_COMMENTS_URL` 修改；设为空字符串并重启可关闭评论区。Docker 修改环境变量后需重新创建容器。

验证：224 项 Python 回归测试、现有前端回归检查、4 项评论回归测试及 7 项官网演示测试通过。已验证浏览器提交评论、后台审核、公开读取与举报处理，验收评论已清理。
