# bata 更新说明

## 2026-11-01 热片统一影片墙与网络诊断

- 连接检测改为弹窗，显示30站连通情况、HTTP状态及耗时；检测中可关闭后重新查看。
- 热片改为统一去重影片墙，保留多来源链接和原始名次，增加演员、片商、标签及来源提供的浏览/收藏/评论等字段；新增FD2列表，现有4站适配，不代表30站全部接入。
- 年龄确认提供CookieCloud设置引导，已启用同步时使用匹配域名Cookie；设置新增Chrome、Edge官方商店及官方Releases入口。
- 管理员可输入Clash/Mihomo控制器、Secret及内网HTTP/mixed代理地址，页面再次确认后临时切换GLOBAL测试节点出口和所选站点，完成/取消后尝试恢复；恢复失败明确告警。
- 上传原始完整YAML后，可生成按已测可达域名筛选节点的完整替换配置下载。输出包含原配置敏感信息，必须先备份、经Clash校验后手动覆盖，不自动改写或安装。
- Clash流程已完成离线模拟与权限/恢复/导出测试，尚未在用户真实Clash上实测；出口与站点可用性以部署环境为准。
- 本轮通过推送main触发Docker bata镜像发布流程，不将Git标签更新误作镜像发布完成。


## 2026-11-01 热片发现与站点检测

- 热片页新增全部／有码／无码标签和最新／最热切换，按来源分组展示，不混算跨站热度。
- 新增30站批量连接检测，后台限并发执行，显示进度、HTTP状态、耗时及年龄确认、地区限制、验证拦截、超时等原因；批量检测需要管理员权限。
- 首批影片列表接入 FALENO、DAHLIA、FREE JAV BT；其余站点目前仅检测连接，不代表已接入榜单。外站可用性以部署环境为准。
- 列表支持显式刷新、冷却、缓存及失败后保留最后成功数据；固定来源、逐跳公网校验和 TLS 验证，不使用用户登录态或自动下载资源。
- 同步离线演示、使用说明与30站调研。此标签更新不会自动部署本地容器，也不会触发当前仅监听 main 的 bata 镜像工作流。


## 2026-10-22 控制台与影片详情更新

- 将概览页的紫色强调、圆角卡片与柔和分层统一到刮削、AI、下载、爬虫、预设、设置、个人中心、常用弹窗与登录页，支持明暗主题及手机布局。
- 评论帮助改为信息图标与“格式说明”，保留 300 字符限制、安全 Markdown 和时间标签说明。
- 剧照支持点击放大、前后切换、方向键、Esc、加载失败提示和焦点恢复；隐私模式继续模糊图片。
- 影片详情仅保留一个随导航可见的关闭按钮，扫描任务同样可关闭。
- 保留最新的服务端女优目录搜索与分页、评论分页及概览重复卡片修复；远端最新 README 保持有效。

## 既有功能与修复

- 评论正文和回复限制为 300 字符，支持安全 Markdown；`30:15`、`1:02:03` 等时间标签可控制已打开的 Jellyfin/Emby 播放器从对应位置播放。评论内容旁提供紫色主题的“格式说明”，分组介绍字数、Markdown、时间标签和限制。
- 移除概览封面上的刮削次数徽标；影片评论新增回复与取消回复，显示被回复评论的作者和摘要。回复沿用评论审核、限流与封禁规则。
- 修复单独提交某个分 P 时被拆开刮削：同目录、同番号的分段合并为一个任务，在同一影片目录输出 CD1/CD2 文件；补充 P1/P2 命名识别。明确多选保持所选范围，下载完成回调不收集其他下载文件。
- 评论、点赞和举报改为按风险验证：先检查额度，必要时才要求 Cloudflare 挑战；通过后当前评论会话获得信任期，持续滥用逐级临时限制。配合本次 JavSP-Comments 后端更新使用。
- 评论管理新增作者 IP、用户 ID 来源筛选，以及 IP/用户封禁、自动临时封禁查看与解除；IP 加密保存，公开评论不显示来源。
- 修复影片详情后台刷新时中文片名与番号闪烁；概览历史记录改为“刮削 N 次”，明确显示刮削失败或已停止。

- 安全修复：修改密码或删除账号后立即撤销旧登录；普通操作员无法读取预设密钥、原始配置和爬虫源码；登录失败按 IP 和用户名限流，HTTPS 登录 Cookie 加 Secure。反向代理部署须设置 `JAVSP_WEB_TRUSTED_PROXIES`，仅信任指定代理提供的客户端 IP 和协议。
- 评论个人中心新增退出当前设备、退出所有设备和修改 PIN，支持使用 `用户名#标识` 登录；配合 JavSP-Comments 的身份额度、举报分页和会话撤销修复使用。
- AI 模型列表兼容嵌套列表和模型名称字段；429 限流最多重试两次，同站点重定向保留认证。
- 修复 Jellyfin 密钥认证：使用标准 MediaBrowser 认证头，并支持媒体库列表兼容端点。
- 刮削预设新增已有影片覆盖方式：从不、总是、按文件大小、仅保留最新。大小或修改时间相同时保留已有版本；保留时不移动源影片，不改写已有资料与图片。多段影片先统一检查再整理，替换失败会回滚影片文件。曾覆盖已有内容的任务不提供文件还原。
- 概览与详情参考 jellyfin-library-poster 重做：封面取色渐变背景、左侧标题和右侧倾斜圆角海报拼贴，影片墙保留独立播放按钮；根据输出路径、路径映射和所选媒体库匹配影片，打开对应服务器的外部播放页面。匹配到多个服务器时可选择播放入口。

- 重做概览媒体库：突出封面墙，加入番号、片名和女优搜索，保留排序、分页、多选与隐私模式。
- 重做影片详情：重新安排封面与资料、横向剧照和评论，文件路径与刮削记录可展开查看。
- 重新生成 247 张头像，去除上下黑边后从正中心裁切。
- 普通评论默认直接发布，疑似广告待审核；后台可分别设置用户名和评论禁用词。
- 评论后台改为表格，支持组合搜索、表头排序和批量发布、删除、恢复、处理举报。
- 删除的评论进入回收站，默认保留 30 天，可设置 1–90 天；到期后定时彻底清理。

已有待审核评论保持原状态。广告规则为初步筛选，管理员仍可处理误判与举报。调整保留天数只影响之后删除的评论。
