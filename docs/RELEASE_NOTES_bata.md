# bata 更新说明

- 新增个人中心，点击右上角头像进入，可设置公开用户名、选择头像并查看自己的评论。
- 内置 247 张女优头像，标注姓名，支持按名字搜索和分页选择。
- 右上角和评论区显示个人头像与用户名；个人资料与评论身份跟随当前 JavSP WEB 登录账号保存。
- “我的评论”展示待审核、已发布和已隐藏的评论，以及点赞数量。
- 评论支持点赞与取消点赞，同一身份只计一次。
- 发表评论、点赞和举报时使用 Cloudflare Turnstile 人机验证，并保留服务端频率限制。

用户名是公开显示名称，不改变原有登录账号。旧版未记录作者的评论无法仅凭昵称归入个人中心；修改资料后，新评论使用新头像与用户名，旧评论保留发表时的资料。

验证：226 项 Python 测试、前端回归测试、9 项评论服务测试通过。普通浏览器已完成真实人机验证、评论提交、后台审核、个人评论查询和点赞验收。
