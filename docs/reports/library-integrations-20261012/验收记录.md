# 模型列表、覆盖策略与媒体库界面验收

日期：2026-10-12。改动已写入当前工作区，未构建安装包或部署。

## 功能结果

- AI 接入：模型列表支持标准 `data`、`models`、嵌套列表、字符串列表及模型 `name` 字段；兼容完整 `/responses` 等接口地址；同站点重定向保留认证；短时 HTTP 429 最多重试两次，持续限流仍显示真实错误。
- 刮削预设 → 文件夹整理：新增“从不、总是、按文件大小、仅保留最新”。最新按文件修改时间比较；大小或时间相同时保留已有版本。保留时跳过整部影片，保留源文件及已有封面、剧照、NFO；不同视频扩展名也参与比较。替换多段影片失败时回滚影片文件，已有目录不整体删除。
- 概览与详情：深色封面墙、封面播放按钮、详情背景与剧照区域，保留搜索、排序、分页、多选、隐私模式与资料编辑。桌面及手机视口均未发现横向溢出。
- 外部播放：根据整理路径、路径映射及所选媒体库查询真实影片 ID，打开 Jellyfin 或 Emby 的外部影片页面。支持根地址、`/web/`、完整 `web/index.html` 地址及反向代理前缀；多个入口显示媒体库选择弹窗；弹窗被拦截时提供链接；播放 URL 不携带 API 密钥。
- Jellyfin：改为标准 MediaBrowser 认证头及 X-Emby-Token，兼容读取媒体库的备用端点；连接错误不再显示包含密钥的请求地址。使用用户提供的服务器与密钥实测 `/Library/VirtualFolders` 返回 HTTP 200。

## 验证

- Python 全量回归：251 项通过（`tmp/cinema-python-tests.log`）。此后补充及修改媒体地址兼容、已有图片保护与任务播放/还原测试，相关四组共 55 项全部通过。
- 所有现有 `tests/test_*.cjs` 回归通过；补充的播放回归也通过，覆盖单入口跳转、错误关闭空白页、多入口选择、弹窗拦截及链接协议过滤。
- `node --check` 与 `git diff --check` 通过。
- 浏览器验证：单入口打开外部影片页，多选计数正确，隐私模式 `blur(18px)`，覆盖策略四项均可选择；桌面、手机概览和详情无横向溢出，无页面脚本错误。

## 验证范围

`https://kuaipao.ai/v1/models` 的无密钥探测返回 HTTP 401 和有效 JSON；没有用户 AI 密钥，因此尚未验证该服务的真实授权模型列表。返回格式、限流重试和重定向行为均已用自动化回归覆盖。

浏览器验收使用公共静态演示、12 部模拟影片及本地头像作为封面/剧照占位，播放接口返回模拟地址。截图用于检查布局和交互，不代表真实影片数据；真实媒体库影片匹配和外部链接生成另有后端回归覆盖。

覆盖回滚保护的是影片文件。图片与 NFO 在影片移动前写入，移动失败后这些资料可能已更新；关闭“移动文件到整理目录”时，覆盖策略不参与原地资料更新。曾包含已有内容或替换影片的整理任务禁用文件还原，避免清理原有资料。
