## 实际边界

- 评论数据经服务器；第三方人机验证仍需浏览器连接验证域。
- 多用户共享站点出口 IP 的上游配额，不伪造来源或关闭防滥用。
- 目录监控采用跨平台轮询；首次基线和手动扫描在超大目录/慢挂载上可能较慢，迟到分 P 可导致同一影片再次处理。
- 对旧基础镜像启动器的修复需要一次性替换镜像，不能仅热更新 Python 应用就替换已有 PID 1。
