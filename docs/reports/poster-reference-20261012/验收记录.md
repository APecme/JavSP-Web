# 海报拼贴界面调整

日期：2026-10-12。

参考：[HappyQuQu/jellyfin-library-poster](https://github.com/HappyQuQu/jellyfin-library-poster)，已查看 README 及 Movie.png 效果。该项目生成媒体库封面，未提供影片详情页；本次将其构图用于概览横幅，并延伸到影片详情头部。

## 改动

- 概览采用左侧大标题、竖条英文副标题和右侧倾斜三列圆角海报拼贴，展示当前影片列表中最多九张封面；不足九张时重复组成完整拼贴，没有封面时展示渐变占位。
- 从第一张封面采样主要色相，生成左深右浅的渐变背景。排除极暗、极亮及灰色像素；无法采样时使用默认紫色。无图片时清除上一张封面的配色。
- 详情头部以当前影片封面与剧照组成拼贴，左侧显示片名、番号和播放按钮；下方使用浅色资料区、剧照网格和可展开文件记录。
- 封面墙改用浅色背景和圆角卡片；独立播放按钮位于封面右下角。搜索、排序、分页、多选、隐私模式、资料编辑及外部播放逻辑保留。
- 拼贴全部使用现有影片图片，由 HTML/CSS 构成；不会生成或上传媒体服务器封面。

## 验证

所有现有 JavaScript 客户端回归通过，包括演示资源同步、播放跳转和错误恢复。JavaScript 语法检查及相关文件的 git diff --check 通过。

浏览器使用公共静态演示与模拟影片进行验证：1440px 桌面、390px 手机和 320px 窄屏均无横向溢出；拼贴九张图片正常显示且带倾斜变换；封面采样背景色成功；外部播放跳转、多选、普通封面与拼贴隐私模糊、空媒体库、无封面影片、资料编辑及取消均通过，未出现页面脚本错误。

截图使用本地头像作为模拟封面和剧照，以检查布局，不代表真实影片数据。改动已写入工作区并同步静态演示，未打包或部署。
