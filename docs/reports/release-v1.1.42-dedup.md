# v1.1.42 概览去重验证

## 原因与修复

概览同时收集本地刮削任务和已绑定媒体库条目。没有路径映射时，`/video/...` 与 `/media/...` 的相同目录未合并；同一来源在同一预设中重复刮削，译名或 FC2 编号写法变化也会产生不同输出目录的历史卡片。

- 优先保留已有的完整路径及显式映射匹配，匹配集合按本地卡片 ID 去重，避免重叠映射重复计数。
- 无完整路径匹配时，仅在标准化番号一致、除第一级容器挂载前缀外的完整目录相同且唯一时合并。本规则要求绝对路径至少含四级目录，不仅按番号或片名去重。
- 相同来源文件、预设、标准化番号与输出父目录的历史任务合并为一个概览代表，保留所有 task_ids 和输出目录别名；展示成功且较新的记录。
- 相同服务器/条目 ID 在多个库返回时合并显示并保留库归属。同目录不同媒体条目、不同媒体服务器或歧义匹配分别保留。
- 历史输出目录别名合并后保留全部媒体引用。保留单个 media_reference 的兼容字段，额外引用存入 media_references。
- 不修改数据库、文件、媒体库或路径映射；只改变概览聚合结果。不会自动清理历史物理重复目录，也不会按相同番号隐藏独立版本。

## 验证证据

- 9 项专门回归：挂载前缀差异、译名与 FC2/FC2-PPV 变化、不同来源/目录/预设/番号、歧义相对目录、多服务器、重叠映射、重叠媒体库、同目录多条目，以及分页和分类计数。
- 初始 6 项回归在旧代码下有 4 项失败，证明重复路径和来源的缺陷已复现；修复后 9 项通过。
- 线上只读提取 687 张卡片，仅保留标识与 SHA-256 脱敏路径，独立本地聚合后为 382 张，消除 305 张冗余卡片；全部历史任务 ID 和 350 个媒体条目引用保留。
- 完整 Python 回归 335 项通过，12 个 Node 前端回归脚本通过，git diff --check 通过。
- 线上环境配置、媒体文件及评论服务未变更。正式构建验收以本次发布执行记录为准。
