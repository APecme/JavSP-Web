## 项目已有功能与边界

复核使用目标提交的 `README.md`、`docs/docs.html`、`javsp_web/web/index.html` 及对应后端/前端控制流。当前 README 的后续文档变更仅用于理解产品背景，没有反向充当旧版本承诺。

- **媒体控制台与共享预设。** README 将产品定义为 JavSP 的 Web 控制台，核心为识别、整理、任务、预设、下载器与媒体库联动。`web/assets/app.js:3363–3364` 保留操作员的预设页，`server.py:548–554,907–915` 允许已登录用户读取/转换配置；管理员才可保存预设和管理系统。没有“操作员不得查看预设内容或其中翻译凭据”的明确文档承诺。
- **用户管理。** `web/index.html:93,96` 提供账号名、密码与管理员/操作员角色编辑。文案未承诺改密退出其他设备；`auth.py:43` 等现有管理员授权边界则是明确实现的能力，同名账号复用不得让旧用户继承新账号身份。
- **下载与任务。** README 明确“下载完成后自动刮削”；现有页面提供停止任务、删除、资料编辑、图片重试和还原。它们应在受支持配置与合理组合操作下保持结果一致。
- **挂载盘与故障。** README 明确底层网络文件系统调用可能等待，取消在其返回后停止后续处理。分 P 整理没有声明任意跨文件 I/O 失败时的事务保证；需要恢复能力的故障场景应列明条件和证据，不能表述为正常整理必然丢片。
- **AI。** README 承诺工具结果隐藏凭据，故常见请求头文本脱敏缺口属于该功能未完整实现。管理员配置内网 Ollama、SearXNG 地址，以及保存、测试自定义 Python 爬虫本来是授权能力；不是单凭内网请求/执行 Python 即存在越权。
- **Docker 更新。** README 使用官方预构建镜像，支持网页更新应用代码和手工拉取新镜像，明确 Windows/普通 Python 仅能检查版本。多租户、非可信 Python 沙箱、多个 Web worker 共享数据目录、无参数源码构建均没有现成产品承诺，不能按 SaaS 验收标准倒推缺陷。

## 与本次 AI 翻译需求的关系

目标 beta 的 README 明确 AI 接入与预设翻译服务独立；当时没有承诺“系统 AI 翻译开关 + 每预设 AI 翻译选择”。本次要求新增这一能力与相应 Skills，属于功能扩展，不补记为旧版本缺陷。新功能验收应验证系统开关、预设翻译字段/引擎选择、模型失败行为、设置保存与技能使用是否一致，避免把“有对话模型”误等同于已支持翻译流水线。
