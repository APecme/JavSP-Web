CAPABILITY / 01

从文件名到媒体库，
每一步都清楚。

刮削整理、分类浏览、评论互动和 AI 辅助，在同一个界面中完成。支持明亮／黑暗主题，也可开启隐私模式模糊图片。

01

刮削与整理

识别番号，从多个资料源生成 NFO、封面和剧照。支持批量任务、多 P 整理、自定义命名和覆盖规则。

FILE → METADATA
02

封面墙与女优分类

按女优、片商、媒体库和年份浏览，搜索、排序或多选影片。Gfriends 女优可切换仅显示已有与全部资料。

BROWSE & DISCOVER
03

媒体库联动

读取 Emby / Jellyfin 影片，打开播放页面，整理后刷新媒体库。路径映射适配 Docker、NAS 与媒体服务器。

CONNECTED
04

评论与互动

个人中心、Gfriends 头像、点赞与回复。评论支持 Markdown 和时间标签，可跳转到可控制的媒体库播放会话；评论由独立服务提供。

SHARE & REPLY
05

AI 助手与翻译

接入自己的模型，辅助刮削、翻译和任务分析。支持模型列表、网页读取、上下文压缩与 Skills。

AI ASSISTED
06

自动化与任务管理

qBittorrent 下载完成自动刮削，定时扫描与 CookieCloud 同步；用预设管理规则，随时查看进度、日志和失败原因。

AUTOMATE & TRACK

WORKFLOW / 02

从第一次运行开始，
保持掌控。

安装后先处理一个影片目录，确认结果，再按需要开启定时任务或下载完成自动刮削。

01

挂载你的影片目录

Windows 可直接选择文件；Docker 先挂载目录，再使用容器内路径。

02

选择预设并启动

为不同来源或媒体库保存独立规则，随时切换。

03

检查结果，交给媒体库

查看影片资料和输出文件，再按需刷新 Emby / Jellyfin 媒体库。

GET STARTED / 03

选择你的运行方式。

两种方式都包含完整的 Web 控制台。首次登录后请立即修改默认密码。

01

下载并运行

从 GitHub Releases 下载最新的 JavSP-Web.exe，双击启动，程序会自动打开登录页。

下载正式版 ↗
下载 → 双击 → 访问 127.0.0.1:8090
02

一条命令启动

将 /your/videos 换成影片目录，数据会保存在当前目录的 data 文件夹。

查看 Docker 镜像 ↗
docker run -d --name javsp-web --restart unless-stopped -p 8090:8090 -v "./data:/app/data" -v "/your/videos:/video" apecme/javsp-web:latest
