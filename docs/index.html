CAPABILITY / 01

从文件名到媒体库，
每一步都清楚。

把复杂的站点、规则与目录交给 JavSP WEB，留下一个可观察、可重试的流程。

01

识别与刮削

自动识别番号，汇总多个数据源，生成 NFO、封面和剧照。支持单个视频，也支持整个文件夹。

FILE → METADATA
02

任务可视化

三阶段进度、完整日志、失败原因与图片重试，任务发生了什么，一眼就知道。

OBSERVABLE
03

自动化连接

接入 qBittorrent，下载完成自动刮削；同步 Emby 或 Jellyfin 媒体库。

CONNECTED
04

按你的规则工作

创建多个刮削预设，表单和完整 config.yml 都能编辑。定时任务不会互相重叠。

CONFIGURABLE

WORKFLOW / 02

从第一次运行开始，
保持掌控。

不需要记住一堆命令。打开浏览器，按自己的节奏完成设置。

01

挂载你的影片目录

Windows 直接运行，Docker 使用清晰的目录映射。

02

选择预设并启动

为不同来源或媒体库保存独立规则，随时切换。

03

检查结果，交给媒体库

完成后自动写入文件，也可触发 Emby / Jellyfin 扫描。

GET STARTED / 03

选择你的运行方式。

两种方式都包含完整的 Web 控制台。首次登录后请立即修改默认密码。

01

下载并运行

从 GitHub Releases 下载最新的 JavSP-Web.exe，双击启动，程序会自动打开登录页。

打开最新版本 ↗
下载 → 双击 → 访问 127.0.0.1:8090
02

一条命令启动

将 /your/videos 换成影片目录，数据会保存在当前目录的 data 文件夹。

查看 Docker 镜像 ↗
docker run -d --name javsp-web --restart unless-stopped -p 8090:8090 -v "./data:/app/data" -v "/your/videos:/video" apecme/javsp-web:bata
