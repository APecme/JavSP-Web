JAVSP WEB / 使用教程

按主题找到需要的教程。

首次使用从安装开始；已经部署完成，可直接进入对应主题。每个主题独立成页，页内按操作步骤分章。

从安装开始 →打开交互示例 →

主题 01

安装与部署 →

选择适合自己的部署方式，先打通登录、目录挂载和持久化，再开始第一次刮削。

  1. 开始使用
  2. Windows 本机部署
  3. Docker / Compose

主题 02

刮削与整理 →

从单次任务到批量整理，了解预设、分类、分 P 与爬虫之间的关系。

  1. 手动刮削与任务
  2. 挂载盘、STRM 与分 P
  3. 刮削预设与分类
  4. 爬虫与网络

主题 03

AI 助手 →

配置模型和联网搜索，管理对话、上下文、提示词与 Skills，再按需启用 AI 刮削。

  1. 模型接入与对话
  2. 联网搜索
  3. 上下文与生成
  4. 提示词与 Skills

主题 04

自动化与集成 →

用定时规则和下载完成事件触发整理，再连接媒体库与 CookieCloud。

  1. 定时自动刮削
  2. 下载器与路径映射
  3. 媒体库与 CookieCloud

主题 05

维护与排错 →

管理更新、账号和备份，并按任务失败阶段定位常见问题。

  1. 更新、账号与备份
  2. 问题排查
