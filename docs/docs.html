从安装到第一部影片。

JavSP WEB 将 JavSP 的刮削能力放进浏览器。选择适合你的运行方式，完成首次登录，然后创建并启动任务。

首次登录默认账号和密码都是 admin。进入后，请在系统设置中立即修改密码。
01运行服务

使用 Windows EXE 或 Docker 启动。

02检查预设

在刮削预设中按自己的媒体库规则调整。

03创建任务

选择视频或目录并从队列查看处理结果。

Windows

从 Releases 下载 JavSP-Web.exe 并双击运行。程序会进入 Windows 通知区域，并自动打开登录页。

http://127.0.0.1:8090/login
下载最新 Windows 版本 ↗

Docker

将影片目录映射到容器，再在网页中填写容器内路径。以下命令会把当前目录的数据保存到 ./data，并将影片暴露为 /video。

docker run -d --name javsp-web --restart unless-stopped -p 8090:8090 -v "./data:/app/data" -v "/your/videos:/video" apecme/javsp-web:latest
路径提示Docker 内填写的是挂载后的路径，例如 /video/Movies，不是主机上的 D:\Videos。

刮削预设

预设保存网站选择、命名规则、扫描器和网络配置。你可以为不同媒体库或来源创建独立预设，在启动任务时直接选用。

  • 单个文件与整个目录都可以创建任务。
  • 任务队列会显示识别、元数据与图片阶段的进度和日志。
  • 图片失败时可从任务详情重新下载，无需重新刮削整个目录。

自动化集成

在系统设置中添加 qBittorrent、Emby 或 Jellyfin。下载完成可自动创建刮削任务，任务完成后可触发媒体库扫描。

自动刮削规则不会重叠执行

当同一规则的上一次任务仍在排队、运行或重试图片时，下一次触发会被跳过并写入记录。

问题排查

提交 Issue 前，请附上任务日志、部署方式和已脱敏的配置。网络或数据源问题可先在预设中检查代理与连接状态。
