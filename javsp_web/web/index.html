编辑预设

窗口表单按 config.yml 的六个配置分类组织；每项都有说明和备注。也可以直接使用完整 config.yml。

扫描器对应 config.yml 的 scanner，负责识别影片文件、过滤目录和设置扫描规则。
网络对应 config.yml 的 network，设置代理、重试次数和网络请求超时。
爬虫对应 config.yml 的 crawler，选择数据来源和影片信息抓取策略。
整理器对应 config.yml 的 summarizer，设置文件移动、命名、NFO、封面和剧照规则。
翻译器对应 config.yml 的 translator，设置翻译引擎和需要翻译的字段。
其他对应 config.yml 的 other，设置交互、更新检查等通用行为。
